BirdTag — interactive flow demo

A walkthrough of the piece I personally built for BirdTag: Cognito-gated authentication into a signed S3 upload, then species tagging.

⚠ This is a front-end simulation. The real BirdTag runs against deployed AWS infrastructure (Cognito, API Gateway, Lambda, DynamoDB, S3) that can't run from a static file. The auth step and the species result below are simulated client-side so you can walk through the interaction flow I designed — the actual auth logic and Lambda functions are in birdtag_auth_and_upload_demo.py.
1

Sign in (Cognito, simulated)

In production this hits a real Cognito User Pool. Here it just simulates the authenticated state so you can proceed.

2

Upload media (signed URL, simulated)

Real flow: this Lambda function generates a short-lived presigned S3 URL, scoped to your Cognito user ID. Try uploading any bird photo.

Click to choose an image
3

Species tagging (simulated)

Real flow: an ML model tags the species server-side. This demo picks a plausible result from a fixed list to demonstrate the UI, not a real detection.

Real project stack: AWS Lambda, API Gateway (Cognito authorizers), DynamoDB, S3, Python. See the actual auth & upload Lambda handler I wrote for my download here.
