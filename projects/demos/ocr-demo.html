Document extraction — live OCR demo

A working recreation of my document-extraction pipeline, running fully in your browser via Tesseract.js (WASM OCR — no server, no upload to anywhere). Upload a photo or scan of a document with an ID-like code (e.g. "AB123456") and it'll extract the text and flag any matching rows, same pattern-matching approach as the original Python script.
