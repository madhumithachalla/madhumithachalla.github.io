Document extraction — live OCR demo

A working recreation of my document-extraction pipeline, running fully in your browser — no server, nothing uploaded anywhere. Upload an image, a PDF, or a Word (.docx) document, type whatever text or pattern you want highlighted (defaults to an ID-style example: two letters + six digits, like "AB123456"), then download the highlighted result as an image or a PDF.

Image/PDF OCR: Tesseract.js. PDF page rendering: pdf.js. Word (.docx) text extraction: Mammoth.js — all running entirely client-side, your file never leaves your device. Matching logic mirrors document_extraction_pipeline.py, the actual Python script I built for this project, extended here with a user-editable search pattern instead of one fixed pattern.
