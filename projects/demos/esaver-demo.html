ESaver — live weather-to-tips demo

A working recreation of the piece I personally built for ESaver: live weather in, energy-saving tips out. This pulls real current weather (via Open-Meteo, no API key needed) and runs the same recommendation logic from my Kotlin code, ported to JavaScript.

Community Tips Board

The real ESaver app has a Firestore-backed real-time chat where users share their own energy-saving tips as they discover them. This demo is a genuinely working local version of that idea, scoped honestly to what a static page can do without a backend.

ℹ This board is local to your browser (saved in localStorage) — it's not synced with anyone else's, unlike the real app's Firestore-backed real-time chat across all users. Renamed from "chat" to "board" here since nothing is actually live/shared in this demo.

Weather data: Open-Meteo (free, no key required). Recommendation logic mirrors esaver_weather_integration_demo.kt — the actual piece I built for the team project. Community Tips Board is a local, single-browser recreation of the real app's Firestore-backed community chat.
