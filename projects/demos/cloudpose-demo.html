CloudPose

FastAPI + OpenCV pose-estimation microservice, deployed on a Kubernetes cluster I built by hand across three Oracle Cloud Infrastructure VMs, and load-tested with Locust.

What's real on this page vs. not: section 1 runs an actual pose-detection model live in your browser, but it's a different, generic model standing in for the concept — not the real FastAPI/OpenCV service. Section 2 describes the real infrastructure I built, which no longer exists to connect to. Section 3's numbers are randomly generated for illustration, not measured results — I don't have the original Locust report. This exists to avoid exposing the real university coursework code, not to reproduce the real deployment. See the README in cloudpose-pipeline for the full honest breakdown.
